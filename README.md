# AI/ML Student Training Program — Labs & Projects

Hands-on lab work and two mini-projects completed during a Student Training Program on Artificial Intelligence & Machine Learning (2026). All work is in Google Colab notebooks using Python, NumPy, Pandas, Matplotlib and Scikit-learn.

## Projects

| Project | What it does | Key techniques |
|---|---|---|
| [Customer Segmentation for Targeted Marketing](STP_project_module_2.ipynb) | Analyses e-commerce customer behaviour (age, order value, purchase frequency, recency, lifetime value) and groups customers into distinct segments for personalised marketing. | Feature encoding & scaling, PCA, t-SNE, cluster visualisation |
| [Diabetes Prediction (Pima Indians dataset)](Project_2_AIML_Training_Program_Module_3_project_.ipynb) | Predicts whether a patient has diabetes from clinical measurements such as glucose, BMI, blood pressure and age. | EDA, feature scaling vs. standardisation, KNN classification, choosing the best K |
